## 验证过程中修复的具体问题

1. 文件全屏面板关闭时，焦点恢复发生在背景取消 inert 之前，真实浏览器忽略 focus。改为清理完成后恢复，且不抢新弹窗焦点。实际检查返回文件按钮，inert 数量为0。
2. 会话操作面板关闭时原有请求代次失效，会丢掉迟到的“结果不明”响应。命令生命周期保持随会话/主机/权限变化；选项加载使用独立 AbortController。回归覆盖关闭后未知结果仍阻塞，回执接受前不重复交接。
3. 文件面板与自动审批可能同时争抢焦点。全局会话弹窗出现时，同一渲染中隐藏工具面板并清理临时开关，使审批保留唯一模态入口。
4. 短屏运行中设置的禁用原因曾落在正文最下方，现随固定底部操作展示。

## 设计对照结论与限制

- 信息层级/间距：旧手机双页头、状态行和常驻工具条合并，正文起始位置上移；输入区长说明收起，操作入口不丢失。
- 字体/排版：沿用原字体与层级；强度、资源类型、原因不再直接显示原始英文枚举。长模型/标题截断，完整标题在详情可见，正文/代码不推宽整页。
- 色彩/图标/表面：沿用现有明暗 token、Lucide 图标、边框和圆角；警示与停止有原语义颜色，没有新增装饰图、假头像或生成图片。未做仪器化对比度及完整读屏审计。
- 响应式：文件面板1280断点，主导航768断点；相同媒体节点用于切换，避免重建视频。
- 可访问性：主要按钮44px、有可访问名称，新增控件能键盘访问，关闭恢复焦点；200%缩放、完整读屏器和真实触屏仍待验证。

未将本轮本地 UI 结果表述为公网/原生 Codex 验收。真实 iPhone Safari、Android Chrome 的软键盘、安全区、后台恢复、网络切换、公网下载和实际票据续期仍待部署阶段验证。未发布线上页面，用户当前远程访问仍可能看到原版本。
