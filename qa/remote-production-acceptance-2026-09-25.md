## 2026-09-26 原 Codex 会话公网控制

隔离版 Mac 保持独立应用数据目录，仅将 `agentkib` 项目纳入真实 Codex 历史范围。经用户明确同意，macOS Safari 临时获得历史读取及发送权限，没有授予审批、任务管理或文件读取权限。Safari 通过公网控制域名打开原任务“处理测试对话”（thread ID `REDACTED_NATIVE_THREAD_ID`），显示历史与空闲状态；发送一次带有 `AK-REMOTE-PROD-20260926` 标记的无工具测试消息。原生会话完成一轮回复，浏览器显示预期文本并回到空闲；原生 transcript 核对为一条该标记用户消息和一条最终回复，没有重复发送。

首次进入该会话时，原生 follower 因官方 Desktop `app.asar` 头部超过原先 4 MiB 校验上限而降级只读。已将上限调整为 8 MiB 并补充超 4 MiB 回归测试；当前安装的官方 Desktop 版本 `26.917.62051` 经实际读取识别，重新构建的隔离测试包通过 macOS 包冒烟检查，发送能力恢复。`cargo test -p agentkib-codex-bridge --lib` 47 项通过，release runtime 和 Electron 构建通过。

测试后在桌面撤销 Safari 授权：设置页“已授权浏览器”显示暂无，本机隔离配置的 `credentials` 数量为 0；Safari 自动显示“远程访问已结束”，此前的会话内容已清空。本次没有验证手机浏览器、审批、文件与媒体功能，也没有替换已安装应用。Mac 的隔离版中继登记和双通道仍保持在线，供后续真机验收。
