# Codex 远控与产物查看（邀请内测）

这条链路在电脑上的 AgentKib 内运行。关闭手机页面不会停止任务；桌面应选择关闭窗口后保留后台运行。完全退出 AgentKib、休眠或关机会使远程服务不可用，没有安装系统守护进程。

## 桌面设置

1. 在「设置 → 远程连接」开启手机访问。使用 [AgentKib Remote 托管连接](REMOTE-RELAY.md) 时输入邀请码；默认管理 API 为 `https://api.agentkib.com`，安装包内置 frpc，证书私钥和 CSR 在本机生成。
2. 连接就绪后，手机扫描电脑控制地址，输入桌面显示的八位一次性授权码。验证成功即进入 AgentKib，无需回电脑确认或逐项勾选权限。
3. **分享授权码即授予完整远控权限**：包括全部已登记及以后新增的工作区、会话与任务控制、审批和问答、文件与产物，以及主机已支持的附件、队列、会话整理和设置。授权码五分钟有效，成功使用一次即失效；仅交给可信设备。
4. Codex 的原生审批、执行策略、版本兼容、原 ID 交接确认及未知结果阻断保持有效。完整授权不等于自动批准命令，也不开放尚未支持的工作树或分支操作。
5. 已配对的旧浏览器保留原有逐项权限、实验开关和选定工作区范围，不自动升级。需要完整访问时，撤销旧设备并用新授权码重新连接。工作区之外的额外只读目录仍由桌面显式添加；普通远控不能读取任意绝对路径。
6. 桌面可随时撤销某个浏览器；暂停公网访问、完全退出应用和撤销浏览器含义不同，都不等于终止 Codex 后台任务。

本文描述邀请内测实现，不表示托管服务已公开上线或开始收费。`https://remote.agentkib.com` 保留为托管网页入口与 LAN 可信 Origin；它不是上述 API 地址。同网段的 [局域网直连](WEB-HOSTED-LAN.md) 是单独启用的次级入口；桌面 [连接其他电脑](REMOTE.md) 属于原生只读连接，和手机访问分别配对。

中继的程序连接成功不等于可访问。证书、域名或外网探测未通过时，不展示可用二维码。断开中继会恢复本地预览地址；变更服务配置会使旧预览票据失效。

旧官方 broker `https://remote.agentkib.com` 和此前开发配置 `https://api.remote.agentkib.com` 不会自动迁移。用户需明确选择 `https://api.agentkib.com` 并用新邀请码登记；不复制旧地址的登记、pending 文件或凭证，普通重连不会改变已有地址。

注册成功但响应丢失时，用已落盘的请求 ID 和凭证恢复同一登记，不自动重复消费邀请码。设备被撤销后普通重连仍会拒绝；填写新邀请码并点击「重新登记设备」才建立新身份，成功前保留原登记文件。

控制和预览分别使用独立 frpc 进程及 TLS 连接。每 20 秒刷新一次最长 60 秒的授权租约；明确撤销立即关闭公网 sockets，后端失联后租约到期也关闭。休眠唤醒先重新授权。这会暂停远控访问，但不会自动终止 Codex 后台执行。该机制针对正常 AgentKib，不承诺服务端能强制踢掉恶意修改客户端的全部旧连接。

证书提前 21 天续期，临时续期失败继续使用尚未到期的有效证书并提示；过期或校验失败关闭公网入口。首版只有一个节点，节点描述和传输适配接口用于后续扩展，不提供多节点自动切换。

## Codex 执行

- 已打开的官方会话使用受版本与协议校验保护的 follower 通道。不兼容、无原 owner 或状态不明确时，只读并说明原因。
- 首次打开官方会话时读取该会话的完整快照，随后手机实时状态消费 owner 的 revision 增量；每 2 秒核对归属，每 60 秒校验一次完整快照。版本缺口、归属变化或断线会使缓存失效；发送、停止和审批等写操作仍在执行前完整刷新并校验。这里不会在每次手机轮询时读取全部会话。
- 「新建 Codex 任务」从已授权工作区创建，支持选择主机已验证的模型与思考强度；创建成功后再发送首条消息。默认是工作区写入、按需审批。完整授权浏览器可以从主机映射的策略中显式切换，但不能提交任意 cwd、命令行、sandbox 或审核器参数；旧浏览器不会因此获得新权限。
- 输入区显示主机实际模型、思考强度、计划模式、服务档位、执行策略、上下文用量和目标。设置仅在空闲时可改，并在原生回读确认后显示生效；执行中不会让用户误以为当前轮次已经切换。托管会话支持目标创建、修改、暂停、恢复和清除，不创建 AgentKib 自动续跑调度器。
- Plan 位于对话设置；托管选择显示「下一轮」，显式发送后才由原生模式事件确认。Goal 位于添加菜单，更新保留原生状态，启动／恢复单独执行；未确认设置会阻止启动／恢复。预算受限显示「尝试恢复」，不承诺已经继续执行。官方会话 Plan 仅在精确验证的 owner 版本开放，官方 Goal 缺少可靠通道时保持不可用。选中会话的 SSE revision 变化合并读取设置与目标，不轮询全部会话；已有编辑草稿保留，双端修改后需重新载入。
- 「添加」区分手机上传与电脑文件／目录、技能、插件和应用引用。浏览器只提交设备绑定的不透明 ID；桌面和 runtime 在发送前重新检查授权、revision、路径范围、符号链接和资源存在性。当前托管协议已验证文件、目录和技能引用；插件与应用没有可靠原生提及路径时会显示不可用。
- 「执行管理」提供明确交接：先在原客户端结束当前轮次、处理审批及后台命令并释放执行宿主，再勾选确认。使用相同原生 thread ID 和 CODEX_HOME，原生写锁冲突会阻止接管。不会自动关闭原客户端、删除锁文件或 fork。
- 托管会话使用独立 app-server 进程；「释放给原客户端」仅关闭该托管执行宿主。继续在官方客户端打开该原生任务。
- 未知回执不会自动重发。手机显示未知结果并阻止直接重复管理操作；已有托管任务可核对原生状态。恢复依据持久命令账本及原生请求身份，不能确认时继续保留阻断。
- Codex 发送、停止、审批、问答以及创建/交接使用持久命令回执；浏览器仅在 sessionStorage 保存按主机和设备隔离的请求标识，不保存消息正文。页面刷新后查询原请求，`unknown` 或未找到回执不会因手动刷新、空闲状态而解锁。accepted 仅表示请求被接受，审批是否完成仍看原生状态。
- 停止表示中断当前轮次，不代表所有外部后台进程均已退出。

实现与恢复细节见 [Codex 托管说明](CODEX-MANAGED.md)。生产 follower 仍需在具体官方客户端版本上完成真实交互验收；隔离 native writer-lock 测试不能替代这项验收。

## 产物、文件和差异

手机会话的「文件与产物」包含三个视图：

- **会话产物**：分页解析会话里的明确 Markdown 文件引用，经主机核实后展示。不是按最近修改时间猜测，也不会把整个目录自动标成该会话生成。没有文件链接的工具产物可从项目文件浏览；目前不承诺从所有提供方的原生工具载荷自动发现附件。
- **项目文件**：按需浏览授权目录。文件 ID 绑定设备及目录授权，文本读取绑定版本；目录变更、设备撤销使旧票据失效。隐藏文件、已知凭证、原始 agent 日志、链接逃逸与特殊文件受限制。
- **Diff**：只读查看工作区、暂存区和指定提交。项目差异可能包含用户原有修改，不能解释为全部由当前会话生成；不提供远程 commit、push 或回滚。

浏览器可直接预览图片、支持编码的音视频、文本、代码、Markdown、JSON、CSV 和静态 HTML；PDF 提供浏览器打开/下载，其他文件提供下载。没有自动转码、Office 转换或文件云上传。

HTML 以入口所在目录生成明确清单和固定版本快照，默认限制 32 MiB/256 文件，总快照 64 MiB。支持包内相对脚本、样式、图片、字体和 JSON；使用独立 origin 及无 same-origin 权限的沙箱，无法访问主站控制 API。外部 CDN、开发服务器、后端 API、弹窗和 worker 不属于首版支持范围；请将构建 base 设为相对路径。沙箱用于隔离应用权限，不宣称对任意脚本提供绝对断网。

媒体通过原生 GET/HEAD/Range 流播，内存不会按视频总大小分配。票据即将过期时由可信父页面续期，媒体恢复播放位置；文件版本改变则要求重新打开。票据是短效能力 URL，勿分享；绑定设备授权意味着撤销设备后失效，并不意味着已复制 URL 具备额外的接收者身份验证。

## 接口与兼容

现有 `/api/web/v1` 路径保持兼容，增加：

| 接口 | 用途 |
| --- | --- |
| `GET managed/options` | 可用性、模型、主机映射策略、默认值与已授权工作区 |
| `POST managed/create/adopt/release/reconcile` | 管理任务；需要 manage、主机 boot ID 和唯一 request ID |
| `GET files/workspaces` | 文件读取授权根 |
| `GET files/list` | 目录 ID 浏览 |
| `GET files/text` | 文件 ID 与版本读取 |
| `GET artifacts` | 指定会话、工作区和可选 cursor 的文件引用 |
| `GET diff` | 授权项目的只读 Git diff |
| `POST artifact-tickets` | 文件或 HTML 包的预览/下载票据 |
| `GET codex/session-settings` | 原生 `current`、下一轮 `selected`、`applicationStatus`、主机默认设置、逐字段写能力、`options.collaborationModes` 与上下文用量；新增字段缺失不推断已支持 |
| `GET codex/goals` | 原生目标、预算、token 消耗、运行时间及可用操作 |
| `GET codex/context-options` | 当前会话可引用的电脑文件／目录、技能、插件和应用候选 |
| `POST codex/settings` | 按 revision 更新下一轮设置或恢复主机默认 |
| `POST codex/goal-*` | 设置、暂停、恢复或清除原生目标；`goal-set.intent` 为 `start`／`update`，预算省略保留、null 清除 |

预览 origin 的 `/p/...` 只处理票据内容，拒绝控制 API；主 API 继续校验设备、Origin 和 CSRF。`GET access` 的 `pairingMode=code` 表示支持授权码直接连接；缺少字段或为 `confirmation` 时保留旧确认流程。新授权凭证含 `device.accessMode=full`；旧凭证不自动增加此标记或扩大授权。执行账本与可重建会话索引分开保存。

## 验证边界

预览默认每台电脑合计 2 MiB/s，在高级设置保存后生效。大文件同时最多 8 路、每个配对设备最多 4 路，超额返回 429 与 `Retry-After: 1`；控制与预览的服务端代理另有独立限额。视频仍受主机上行带宽、运营商链路和浏览器编解码支持限制。续票暂时失败会保留仍有效的预览并重试，到期或撤销后停止；续票成功恢复播放位置，文件版本改变则要求重新打开。

自动化覆盖授权、旧配置兼容、命令去重与恢复、原生跨进程写锁、目录逃逸、HTML 清单与隔离头、媒体 Range、票据撤销、UI 异步竞态和本地真实 frp/TLS 透传。实际执行结果记录在 [本轮 QA](../qa/codex-remote-artifacts-2026-09-24.md)。

公网 DNS/证书签发、iPhone Safari/Android Chrome 实机、蜂窝切网、长期证书续期及当前官方 Desktop 的发送/审批/问答仍需实际部署验收。代码完成、本地测试通过和线上验收完成是三个不同状态。

本次单节点完善及安装包验证另见 [单节点验收记录](../qa/single-node-remote-2026-09-24.md)。

## 附件与原生高级操作

新授权码连接的浏览器可在 Codex 输入区选择文件或粘贴图片；旧浏览器仍需原有附件权限。每文件上限 25 MiB、每条消息合计 100 MiB／10 个附件、主机存储上限 2 GiB。未发送草稿 24 小时过期；已发送或结果不明的引用保留，显式删除会影响历史引用。上传文件只保存在电脑私有目录，不自动解压、执行，也不因此扩大 Codex 沙箱范围。图片交给原生图像输入；其他文件以文件引用交给原生任务，能否读取由原生权限决定。

运行中的托管任务可追加指令，或加入官方待发队列；后者会在当前任务完成后自动执行。会话工具提供按能力开放的重命名、归档、取消归档、分支会话及下一轮模型设置。仅有历史读取权限的浏览器不会因此取得这些能力。页面待处理入口集中提示已经收到的审批和问答；关闭页面后没有系统推送。

新接口包括 `GET codex/capabilities`、`GET codex/queue`、`POST codex/<action>` 及 `POST/GET attachments`、`POST attachments/delete`。仍使用现有同源 Cookie、Origin/CSRF 与设备授权，不接受浏览器传入任意原生 RPC 或本地文件路径。断线后的未知写操作先查原请求回执和原生证据，不能通过重命名、恢复或刷新绕过。
