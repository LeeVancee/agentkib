# 会话互通：方向、版本与验收边界

本页描述工作树中的实现，不代表已发布版本。统一中间格式仍是 `SessionDocument`；来源解析、目标转换、原生导入与 Web 托管控制分别判断能力。新目标目前为实验适配，不能将离线导入成功理解为真实模型续接已验收。

## Cursor IDE 本机连接

在本机工作区的会话页点击“连接 Cursor 窗口”，无需已有会话或导入记录；配对成功后自动刷新历史一次。会话交接中选择 Cursor → IDE 也可连接。先查看并校验随应用打包的 VSIX，手动安装到选定的 Cursor profile。AgentKib 不调用任意安装命令，也不猜测默认用户目录。macOS 本机生成 120 秒一次性连接挑战，在对应单文件夹窗口执行 `AgentKib: Connect This Workspace` 并输入挑战。多个窗口须显式选择；CLI 与 Agents Window 的能力分别显示。

扩展报告实际 storage URI、Cursor 安装版本及工作区；Runtime 只接受已核实的 `User/globalStorage/state.vscdb` 布局。命名 profile 的其他布局目前拒绝。私有 socket 绑定 profile、工作区、窗口 lease、计划哈希和操作 ID；持久桥接凭据只进入扩展 SecretStorage，Runtime 仅保存哈希。两个窗口的凭据独立存放，存在多个绑定时自动重连被拒绝，须选择原绑定生成新挑战。断开会撤销旧凭据、该绑定所有未消费的重连挑战与读取能力，离线绑定也适用；断开成功后界面移除对应连接码。保留操作恢复所需的身份，明确重新连接时须生成新挑战，沿用原 binding。

工作区目录、安装或数据库失效时，相关绑定仍可查看并断开，不影响其他工作区首次连接或读取。失效来源的已索引历史保留，但不能继续读取正文、导入或续接；资源恢复后仍须通过原版本、安装哈希与路径校验。

导入计数不是成功凭据。180 秒期限内必须找到唯一新原生 UUID，并核对完整 root、全部 blob、角色和正文后才记录并打开目标；选中 ID 也须一致。结果未知时只核对，不重发导入；启动失败只重开既有目标。会话恢复面板可直接重连原绑定，来源已不可用也无需重新分叉。恢复校验保留完整历史前缀和原始 blob；新增轮次可复用旧正文的内容哈希，但每次复用须按顺序匹配一个实际新增的同角色、同正文界面轮次。Runtime 晚于 Cursor 启动时连接使用 2–30 秒退避，重连不重放导入。

Windows/Linux 原生桥接关闭；协议测试与实机验收分别记录。工具摘要及附件省略展示在预览，必要文本不可保留时拒绝；未验证的长历史不截断后冒充完整续接。本轮不增加 Web 安装、扩展连接或任意命令入口。

## 审查、失败与恢复

文件写入目标仍沿用既有 ChangeSet。命令导入目标在 Changes 中展示应用数据目录内的 `plan.json`，其中包括冻结并脱敏的来源文档、目标投影、载荷、版本/存储身份及操作指纹。它是**准备文件**；批准后才会调用目标 CLI，目标内部数据写入不伪装成 JSONL 文件 diff。

OpenCode/Hermes/OpenClaw/Cursor IDE 的历史工具调用转换为标注的历史文本，工具参数/原始输出与附件可能省略；预览明确显示损失。转换器不保留可再次执行的历史工具调用。必要用户/助手正文发生未知变化时拒绝导入。新目标不支持尚未经验证的 AgentKib 长历史检索；超出完整窗口时不静默截断。

OpenCode/Hermes 已追加合成 Grok 工具与附件记录的官方禁网导入回读，确认完整目标文本投影及无可执行工具字段，见[补验记录](../qa/full-interop-rich-offline-2026-09-30.md)。该证据不表示附件本体保留，也不替代全部来源的公开流程、界面或真实回复验收。

每次明确分叉有独立操作 ID；开始外部导入前先写入持久化尝试标记。重复 RPC 复用记录；导入后必须核验归属、正文、角色及已知结构，失败不得启动模型。Hermes 出现父/子会话关联可能被官方恢复流程重定向，目前保守拒绝自动恢复；OpenCode 已撤销的历史同样拒绝。CLI 非事务导入发生超时、断流、退出或部分写入时，保留现场并显示待核对；不会因响应丢失再次导入，也不会自动降级为文件交接。会话页可查看持久化记录并核对/恢复已有目标。无法确认安全删除时不自动清理目标对象。

OpenClaw 使用固定版本自带的写入函数维护原生索引与投影，写入期间持有官方状态锁。已有 Gateway 或本地 TUI 占用时拒绝导入及自动恢复，不停止用户进程。目标数据库必须已是已验证版本，AgentKib 不自动迁移旧存储。启动仅打开已核对的本地会话，不发送初始提示；正文、身份、工作区或代际改变时拒绝恢复。

后台执行器串行处理，有界队列容纳 8 个等待请求；普通 Runtime 请求继续响应。退出时拒绝待执行请求，外部等待可取消，已开始且结果不明的操作保留记录。不承诺目标 CLI 的跨进程事务、强杀或断电恢复。

上下文文件交接仍可由用户明确选择，它创建引用文件，不计入原生互通验收。本轮没有新增这些 Agent 的 Web 控制、权限、MCP 自动配置或配置资产迁移。
