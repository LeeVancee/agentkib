# MCP 服务管理、Agent 接入与工具分配

桌面「全局资产目录 → MCP」提供三个独立流程。全局与工作区设置分别保存；Web 不提供这些管理写入接口。DeepSeek Harness 保持只读范围，不在接入选择中。

批量接入的检查原因、写入与恢复回执，以及原生收录的逐项警告，随界面语言显示简体中文、繁体中文、日语或英语。

## 管理服务

1. 先选择全局或一个工作区，搜索现有服务，或选择「添加服务」「收录服务」。
2. 手动添加使用表单和同一份 JSON 草稿；已有服务的 ID 不可修改。工具白名单、包信息等高级字段保留在 JSON 中。
3. 收录支持 AgentKib 单项、`mcpServers`、Codex JSON/TOML、OpenCode local/remote 和命名对象。逐项查看识别结果；SSE、未知行为字段和不能等价转换的条目会被拒绝。OpenCode 的环境／文件替换、Claude/Hermes/OpenClaw 的环境表达式，以及 Cursor 的环境／工作区表达式暂不代为展开；带这些表达式的对应原生配置须先手工转换，秘密改填凭据字段。通用 `mcpServers` 粘贴中的变量语义不明确时同样拒绝，不自动读取来源环境或文件。明确使用 AgentKib 单项格式时仍遵循 Hub 的字面值语义。
4. 新服务默认停用。收录不会启动服务、安装包或修改原应用。原应用的秘密只识别所需键名，不复制原值；自己粘贴的结构化凭据保存在本机私密文件中。命令、参数或 URL 中的内联凭据（包括 `--header` / `-H` 携带的敏感 Header）不能直接收录，须改为对应服务支持的环境变量或私密凭据字段。
5. 同 ID 且配置相同的条目跳过并保留原状态。冲突项默认跳过，可另取 ID 或明确替换当前作用域定义。工作区继承项须先建立本地覆盖。同一原生来源只发生格式等无关变化时，可选择「重新确认来源」更新来源快照，同时同步来源要求的凭据键名，已有启用状态、凭据值和工具规则保持不变；继承定义须在所属作用域重新确认。
6. 编辑凭据时按键选择保留、替换或删除。搜索与复制仅包含脱敏公开配置。修改连接地址会清除该连接的旧 OAuth 身份，需要重新授权。
7. 收录后自行启用并探测服务。服务总开关与 Agent 分配相互独立；不能靠取消最后一个 Agent 表示停用，请使用总开关。

OpenCode 显式 OAuth 配置（包括 `oauth: false`）暂不支持等价收录。Hub 的 HTTP 传输会在认证挑战后尝试 OAuth，因此不能静默忽略来源的禁用设置；被阻止的条目不会保存或探测。

原生 stdio 收录同时检查运行目录：Claude Code/OpenCode 的项目级缺省目录固定为所选注册工作区；Codex、Cursor、Antigravity、OpenClaw 已声明的绝对 `cwd` 保留。用户级缺省目录、其余无法确认的缺省目录、相对目录或不支持的目录字段会被阻止，不能借当前选择的工作区猜测原应用的启动环境。Claude Code 的 `cwd` 字段在已检查版本中不生效，因此也不收录。未知或被阻止的定义可在明确运行目录后手动创建 Hub 服务，不自动迁移原配置。

运行实例按当前作用域展示，重启只作用于该实例所属作用域。「停止该服务的全部实例」保留原有行为，会停止同一服务在所有作用域中的实例。

批量启用／停用只处理当前筛选中选中的条目，逐项报告成功、失败或跳过。重试保留原期望状态，只执行失败项；配置刷新失败时停止后续写入并保留已经取得的结果。

公开定义仍存于 `.agentkib/mcp.json`，私密值存于受限的 `.agentkib/mcp.local.json`。新私密记录只覆盖私密字段，避免旧私密快照遮蔽公开开关、地址与目标。保存版本包含参与继承的全局文件；外部修改后必须重新核对。公开／私密写入使用原有 ChangeSet 哈希检查、临时文件、备份和失败补偿，不保证断电下多文件原子性。

## 补齐到 Agent

选择「补齐到 Agent」，明确指定工作区，以及一个、多个或全部支持的 Agent。全局页面不会替你选择第一个工作区。检查结果会列出安装情况、配置文件和项目／用户级范围。

| 检查结果 | 处理 |
| --- | --- |
| 缺少 `agentkib` | 添加 Hub 连接 |
| 已正确绑定 | 跳过，无额外写入 |
| 同工作区的旧端口或无歧义旧别名 | 修复；保留用户停用状态 |
| 其他工作区 | 默认跳过；单独选择改绑并重新预览 |
| 未知同名、身份歧义、损坏配置 | 拒绝该项 |
| 未安装 | 跳过，不安装、不创建其配置目录 |

审阅集中差异后确认。Hermes/OpenClaw 等用户级配置需要单独同意 Home 写入，其绑定可能影响其他工作区。后端保留真实快照，页面只看到脱敏差异；每个文件合并为一份计划，共享 manifest 的哈希一并更新。应用前再次检查注册身份、规范路径、端口、profile、安装情况与文件哈希。

操作只补齐名为 `agentkib` 的连接，不删除其他服务、不启用上游、不调整工具分配。写入后执行只读 Hub 握手及 `tools/list`。已经正确绑定的目标也可以直接验证，无需先应用空计划。**配置已写入和 Hub 可达，不代表目标 Agent 已重新加载**；请在目标产品中重载 MCP 或重启。补偿不完整时保留现场，按回执中的文件与备份路径处理；重试须重新检查和预览。

「从应用读取」中的迁移是另一项操作：只允许迁移已经收录、显式启用、目标分配正确且当前配置已完成探测的服务。迁移预览与应用重新验证原生来源；只调整原应用接入配置，不覆盖已收录定义。粘贴条目不会按名称猜测原文件。

公开配置与迁移预览均限制脱敏处理量。重复或重叠的私密值只匹配原始文本，不继续处理已生成的遮罩；保存前先检查合并后的有效配置，超限时不写入公开或私密文件。迁移预览中，配置中的大量重复嵌套凭据或过多替换工作超限时，整次预览会被拒绝，且不会生成可应用的迁移回执或修改原配置；请简化相关配置后重新预览。系统不会返回只完成部分脱敏的差异。

## 分配具体工具

每个服务的「分配具体工具」按 Agent 保存规则，AgentKib 内置工具单独成组。目录来自当前作用域、当前连接配置的最近一次探测；打开页面不启动服务。暂未发现的既有规则保留并标注。

- **继承默认**：工作区继承全局；没有规则时保持既有行为。
- **全部工具**：包含以后发现的新工具。
- **指定列表**：仅开放列出的工具，空列表表示全部隐藏；不会自动增加新工具。

规则存于全局／工作区 `.agentkib/mcp-policy.json`（`schema_version: 1`），不含秘密，不修改业务数据库。规则取服务开关、目标 Agent、原有白名单的交集；LAN 继续受原白名单限制，内置工具不通过未认证 LAN 开放。

Hub 的目录与调用使用同一规则。即使客户端记住旧工具名，调用时仍会重新检查；启动等待结束及排队实际派发前再次核对。已派发的动作不能撤回。工具目录和活动连接按规范作用域、服务 ID、连接指纹隔离；调整权限无需重新探测。长历史交接依赖的内置归档工具被停用时明确拒绝，不自动放开。

## 验证边界

本轮使用合成配置、临时 Home 和合成 MCP 服务验证，不更改个人 Agent 配置或调用真实模型。自动化、Electron 验收及未验证平台见 [本轮 QA](../qa/mcp-management-2026-10-09.md)。旧单 Agent RPC 分支为兼容保留，新桌面流程使用版本化保存与后端预览 token。
