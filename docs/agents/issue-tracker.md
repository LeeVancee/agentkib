# Issue tracker: None

This repo intentionally does not use GitHub Issues, GitLab Issues, or local issue files.

## Conventions

- Keep requirements and decisions in the current conversation or repository documentation.
- Do not create issue files under `.scratch/`.
- Do not use `gh`, `glab`, or another issue-tracker CLI for this repo.

## When a skill says "publish to the issue tracker"

Do not create an issue. Keep the resulting PRD or plan in the conversation unless the user specifies a repository document path.

## When a skill says "fetch the relevant ticket"

Ask the user for the relevant plan or document path instead.
