独立复核发现的补修：

- 四语操作指引中少数仍残留“桌面”，以及日文通用替换产生重复应用名；先补回归确认失败，再修文案与镜像。

## 沙盒与真实页面

测试只使用合成项目 `northstar-api`、两条合成 Claude 历史、两份合成技能和禁用的 MCP 配置，没有登录或调用模型。

`qa/probes/v15-a-sandbox.mjs` 隔离以下五个目录变量；额外隔离技能库、XDG 和 Electron 配置：

```text
HOME
CODEX_HOME
CLAUDE_CONFIG_DIR
AGENTKIB_BENCHMARK_DATA_DIR
AGENTKIB_BENCHMARK_USER_DATA
```

Electron 使用 macOS Seatbelt 限制网络为 loopback，显式拒绝个人 Agent 目录及凭据文件；测试包装器阻断登录、外链、账号和电脑配对写操作，电脑名及网卡使用示例值。Web 最终复验在同一 Seatbelt 策略下新启动 Chrome，使用全新临时浏览器配置及上述五个目录变量，并通过 Playwright route 再阻断非 loopback 请求；对保留域名 `example.invalid` 的验证请求确认为 `ERR_FAILED`，在发送前被 route 取消。

该机器的外层 Seatbelt 与 Chromium 内层沙盒不能嵌套运行，因此 QA 启动器使用 `--no-sandbox`，保留外层 OS 限制。生产代码没有改变；这套视觉夹具不用于验收 Chromium 进程隔离、真实账号、真实设备配对或公网中继。

Web 通过真实服务的合成一次性授权码获得只读访问；授权码仅保存在临时变量中，没有输出、截图或写入 QA。只读浏览器能阅读历史，控制入口保持禁用。技能部署只向隔离的合成 Agent 目录写入，并经过真实预览、个人目录确认和应用步骤；没有跳过业务确认。

探索与负向检查：

- 技能目标已存在时，预览正确拒绝覆盖；改选空的合成目录后，确认再应用成功。
- 修改合成技能内容后，界面正确显示“本地修改”与需检查配置位置，没有把文件变动当成已验证部署。
- 初次 Web 夹具把保存格式写成裸配置，服务报 `invalid_saved_configuration` 并拒绝监听。已修夹具为真实 `{config, credentials, remotePairingInitialized}` 结构，未修改生产校验。
- 测试期间重建后，页面曾进入错误回退界面，重新加载后恢复；缺少完整错误日志，不把时间重叠当作根因证明。首次测试启动进程离开的原因同样没有足够证据，未归因到产品；后续启动器改为独立进程并记录生命周期、按身份核验清理。

## 真实颜色证据

运行时：桌面 Electron **44.9.1 / Chromium 152.0.7977.167**；Web Chrome **155**。桌面为应用默认原生窗口，Web 为 1440 × 1000 CSS 像素。

`collectV15ColorMatrix` 使用构建后的生产 CSS，在独立临时节点上遍历各主题和 background/card/muted/sidebar/popover；测主色文字、次要文字、危险文字、透明浅底及按钮。通过浏览器 computed style 解析 sRGB/OKLCH 和透明层，不把静态颜色函数当作真实 CSS 证据。

| 范围 | 主题状态 | 样本 | 不达标 | 最低对比度 |
|---|---:|---:|---:|---:|
| 桌面 | 5 主题 × 浅/深 | 700 | 0 | 4.509583:1 |
| Web | 蓝/紫/绿 × 浅/深 | 420 | 0 | 4.566204:1 |

矩阵中的 hover 行是精确生产 token 的模拟组合，单独标记为 `semantic-hover-token-simulation`。此外逐套主题用 Playwright 真正移动鼠标至生产 Button 类构成的独立 QA 按钮，验证实际 `:hover` 匹配：**32 个状态、256 个文字样本，0 失败，最低 4.552569:1**，同时测链接、次要文字、选中项、未选中标签、历史权限说明及真实 `::placeholder`。这些节点不触发产品操作；与实际应用页面截图及组件回归分别交叉检查，不宣称遍历了全部产品组件。

桌面构建没有实例化 `bg-sidebar` 工具类，Web 没有实例化 `bg-primary/10`；对应额外组合用 CSS token 构造底层并在 JSON 标记 fallback，不假称这些工具类存在。其余正常文字工具类和对应 token 无不一致。所有 QA 节点及临时根主题属性在采样后恢复。

VTRON 浅色代表值：主色文字对白底 5.787、对 `#fafafa` 5.544、对 `#ebf0ff` 5.081；次要文字对 `#fafafa` 5.183；白字主按钮正常/悬停 4.666。危险浅底最低背景组合仍为 4.510。各主题前后值、保留理由及精确实测见上述颜色分录和 JSON。

## 设计差异与边界

- MCP 现有配置作用域卡片、8 个 Agent 列、资源库功能位置、远程连接长页和终端连接步骤均保留；这些结构属于 B～D，本批只改术语和颜色。
- 分段控件只调整浅底和文字颜色，未改交互或结构。网络目标的“主机”继续保留技术含义。
- 其他主题经授权修复不达标文字/按钮组合，原本达标角色不动；颜色分录列出每个前后值。未全局更换独立图标或禁用样式。
- 本批不以真实账号、真实会话、模型响应、Windows/Linux 原生界面或远程公网连接作为验收范围。
- 额外观察：技能内容预览会出现红色 `null` 提示。核对基线后，`SkillFileBrowser` 原本就用 `error !== undefined` 判断 TanStack Query 的空错误值；本批仅改该提示的文字颜色，没有引入这一判断。按 A 批范围保留现状，没有夹带这项错误处理修复。
